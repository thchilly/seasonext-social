# Reference data

`climadat_crete_pr_1981-2019.nc`: mean annual and mean October precipitation over Crete,
1981-2019, on the native ~1 km CLIMADAT-Grid (land cells only, 34.8-35.72 N,
23.45-26.35 E). Derived from CLIMADAT-Grid v1: Varotsos, K.V. et al. (2025), Earth
System Science Data 17, 4455-4477, doi:10.5194/essd-17-4455-2025; data
doi:10.5281/zenodo.14637536. Licence CC BY 4.0. Used as map background in figures.
